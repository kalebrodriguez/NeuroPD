# ADR 0019: Do the classification conclusions depend on ds002778? (pre-declared)

- **Date:** 2026-11-24
- **Status:** accepted (written and committed before the re-run below was computed)

## Context
The ds002778 README (read on 2026-11-11) strongly advises against classifying PD
versus controls on that dataset, because it has too few patients (15 PD, 15
controls after QC). The project uses ds002778 in two ways:
- as one of three external test sets (ADR 0014, ComBat);
- as a training and held-out site in leave-one-site-out training (ADR 0016).

Whether to keep it in the paper's classification results is the owner's decision
(`docs/submission_checklist.md`). This analysis tells the owner whether that
decision changes any conclusion. The owner asked to continue (2026-11-24). No new
data are needed.

Analyses that never used ds002778 are unaffected and not repeated:
- confirmatory transfer (ADR 0013);
- the within-PD clinical analyses (ADRs 0017, 0018).

ds002778's descriptive group statistic in ADR 0015 (aperiodic Cohen's d) is not a
classification, so it is out of scope.

## Decision: pre-declared sensitivity analysis
1. **Leave-one-site-out without ds002778 (new computation).** Re-run ADR 0016
   with three sites: ds007526, ds004584 and ds003490. Everything else is
   unchanged: arms A (ds007526 only), B (pooled) and C (per-site z then pooled),
   the same models, features, seeds and bootstrap. ds002778 is removed from
   training as well as testing.
2. **ComBat without ds002778 (re-tabulation, no new computation).** ADR 0014 fits
   each development–external pair separately, so the ds004584 and ds003490 results
   do not involve ds002778. Its criterion (ComBat beats no harmonization in every
   external cohort) is re-applied to those two cohorts. Disclosure: these
   per-cohort numbers are already public in `docs/combat.md`.
3. **Site identity versus disease transfer** for ds004584 and ds003490 is
   re-stated from committed results. This is also already known.

**Pre-declared rule.** The classification conclusions are called **unchanged
without ds002778** if all of the following hold. Otherwise each change is
reported, and the manuscript must state it.
- (a) In each remaining external cohort, site identity AUC exceeds disease
  transfer AUC.
- (b) The ComBat criterion is still not met for either variant.
- (c) H2 (arm B or C beats arm A at every held-out site, now ds004584 and
  ds003490) is still **not supported**, as in ADR 0016.
- (d) Directional: arm C's AUC at ds003490 still exceeds arm A's. This is the
  "small sites" observation from ADR 0016. It is reported, not tested.

## Consequences
- If the conclusions are unchanged, the owner can remove ds002778 from the
  classification results, or keep it as a supplementary analysis, without
  changing what the paper concludes.
- If anything changes, the paper's conclusions partly rest on a dataset whose
  authors advise against this use. That must be said plainly.
- Either way, the choice stays with the owner. This ADR does not remove
  ds002778 from any existing result.
