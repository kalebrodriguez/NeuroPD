# Cross-Dataset Harmonization & Aperiodic Features

> Generated by `scripts/evaluate_external.py` (baseline vs `--harmonize per_cohort_zscore`) on 2026-08-28 from the git-ignored feature matrices, which now include the aperiodic (1/f) features (ADR 0012), giving **230 features** (was 210). Each model is fit on the full development cohort and evaluated once on the full external cohort; the external cohort is never used for tuning. See ADR 0011 (harmonization) and ADR 0012 (aperiodic). Intervals in the source reports are 95% participant-level bootstrap CIs.

## Question

The central finding is that the shared feature space is dominated by **site/acquisition** (dataset identity predicts at AUC ≈ 0.95). This analysis asks: does **train-safe per-cohort standardization** — aligning each cohort to its own mean/SD, using only unlabeled features (spec §6.2) — improve cross-dataset transfer of the *disease* signal? And does adding the **aperiodic** feature change transfer?

## Result — harmonization does NOT improve transfer

External **balanced accuracy** (and ROC-AUC), EEG models, 230 features:

| direction | model | none: bal acc (AUC) | per-cohort z-score: bal acc (AUC) |
| --- | --- | --- | --- |
| ds007526→ds002778 | logreg | 0.633 (0.720) | 0.600 (0.751) |
| ds007526→ds002778 | svm_linear | 0.633 (0.680) | 0.633 (0.711) |
| ds007526→ds002778 | random_forest | 0.600 (0.767) | 0.467 (0.756) |
| ds002778→ds007526 | logreg | 0.654 (0.695) | 0.644 (0.676) |
| ds002778→ds007526 | svm_linear | 0.664 (0.698) | 0.639 (0.688) |
| ds002778→ds007526 | random_forest | 0.523 (0.603) | 0.588 (0.597) |

Full tables: [`external_transfer.md`](external_transfer.md) (frozen baseline, 210 feats) and [`external_transfer_per_cohort_zscore.md`](external_transfer_per_cohort_zscore.md) (harmonized, 230 feats).

**Interpretation.** Per-cohort z-scoring leaves external balanced accuracy essentially unchanged (linear models stay ≈0.60–0.66; the random forest moves within noise in opposite directions per direction). ROC-AUC nudges up for the linear A→B models and down for B→A — no consistent gain. This is an informative (near-)null: **the between-cohort difference is not merely a global per-feature location/scale offset** that standardization can remove; it is higher-order (distributional/topographic), consistent with site identity being separable at AUC ≈ 0.95. It also aligns with the earlier sensitivity result that *relative* (already-normalized) band power is what transfers — normalization at the feature-definition stage helps, but a second global standardization adds little.

## Aperiodic features

Enabling the aperiodic 1/f exponent + offset (ADR 0012) widens the participant matrix from 210 to 230 features (2 features × 5 regions × 2 robust statistics). Cross-dataset transfer is essentially unchanged versus the frozen 210-feature baseline (linear-model external bal acc ≈ 0.63–0.66 either way), i.e. the aperiodic component does not add cohort-invariant disease signal here — itself a useful negative result. The exponent remains valuable as an *interpretable* descriptor separating aperiodic tilt from oscillatory power (see the biomarker explorer).

## Caveats

Small external cohort (n=30 in the A→B direction) keeps all differences directional, not conclusive. Per-cohort standardization is transductive (uses the target cohort's unlabeled distribution), so it characterizes *analysability*, not a deployable model. A peak-separated FOOOF/`specparam` aperiodic fit and an empirical-Bayes ComBat harmonization are natural follow-ups.
